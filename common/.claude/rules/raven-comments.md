# Comment Rules

- Say what the code cannot: why, a constraint, a consequence not visible here.
- A comment restating the line below is noise.
- Strip process narration: "Now we need to", "First, let's".
- Do not assert domain facts you have not verified.
- A comment that no longer matches its code is a bug.
- Issue numbers and fix history go in the commit.
- More than a line? raven-write-prose applies.
