# Comment Rules

- Say what the code cannot: why, a constraint, a consequence not visible here.
- A comment restating the line below it is noise. Delete it.
- Strip process narration: "Now we need to", "First, let's".
- Do not assert domain facts you have not verified, like "the usual case".
- A comment that no longer matches its code is a bug; fix both together.
- More than a line? raven-write-prose applies.
